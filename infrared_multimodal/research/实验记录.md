## RTX 4060 流水线验证

环境为 RTX 4060 Laptop GPU 8GB、`mmi-unet` / PyTorch 2.5.0 + CUDA 12.1。完整 288×144、batch16（P=4,K=2）的合成前向/反向测试覆盖 AGW、center、unbounded、BCRT；四组有限梯度且真实更新参数，AMP scaler 无跳过；约 1,027–1,029 MiB 峰值**allocated tensor**。随机权重、合成 batch 的 inference 测试约 17.08 ms / image batch 1（不含图片 IO/检索）。这些数值只验证程序执行，不是 ReID 识别结果或吞吐对比基准。记录在 `results/pipeline_check.json`。

## RegDB 开发集预实验

一次固定 seed=1、trial1 的研究用开发切分：206 个官方训练身份中，165 个训练，41 个身份仅用于开发验证；两组身份互斥。每变体 8 epochs × 40 steps、batch 16、相同 ImageNet 初始化和图像预算；只在最终 epoch 于这 41 个 held-out 身份进行 VIS↔IR 全 gallery 检索。协议不是官方 RegDB test。

| 变体 | V→I Rank-1 / mAP | I→V Rank-1 / mAP | 双向均值 Rank-1 / mAP |
|---|---:|---:|---:|
| AGW / CE+WRT | 7.32 / 12.94 | 11.22 / 13.53 | 9.27 / 13.24 |
| center | 15.85 / 17.31 | 7.32 / 10.99 | 11.59 / 14.15 |
| unbounded residual | 17.32 / 17.89 | 7.56 / 11.66 | 12.44 / 14.72 |
| BCRT | 9.51 / 14.42 | 9.02 / 12.77 | 9.27 / 13.59 |

指标单位均为百分比，来源是 `results/pilot_v1_regdb_dev_{agw,center,unbounded,bcrt}_t1_s1/evaluation.json`。BCRT 在短预算下双向 mAP 只比 AGW 高 0.35 个百分点，低于 unbounded 1.13 个百分点；Rank-1 均值与 AGW 相同。训练轮数不足、单 seed、单身份划分，双向方向的差别也不稳定。此结果**没有证明 BCRT 提升精度**。

同组 BCRT 的有效虚拟对比例约 86–100%，最后训练轮中步长被截断约 30%，解析固定中心的欧式间隔违规数为 0；unbounded 对照在后期 batch 每步平均出现约 20 个间隔违规。零违规仅验证了代码中的有限 batch 几何约束，没有测试集泛化保证。

## 正式协议短预算运行

四组均按 RegDB 官方 train/test identities（trial 1）、seed 1、ImageNet 初始化、batch16、20 epochs×40 steps、初始学习率 0.02、固定最后一轮、无 test-time flip/rerank 运行。每组 800 optimizer updates，不是完整 AGW 120 epoch 训练。测试集只在四份固定最终 checkpoint 上评测一次，没有用于选参数或 checkpoint。指标单位是百分比。

### SYSU 解释边界

SYSU 每个版本只训练一个 20×40-step checkpoint，再用官方 all/indoor single-shot gallery 随机抽样评估十次；十次 gallery 不能当作训练重复。训练身份 395 个、34,167 张图像，800 次更新覆盖的数据有限。AGW 在 all-search Rank-1/mAP 为 5.08/6.36%，远低于近年论文约 80/77% 的完整训练结果，属于明显未充分训练的流程初验，不能用来对模型方法排名。Center 与无约束组在这次短跑略高于 AGW，也不构成稳定收益证据。所有组都在固定最终轮评估，无重排序和测试翻转。完整均值和 history 将进入机器可校验的 `results/official_pilot_v1_summary.json` 与本文。

### 运行完整性审计

`tools/summarize_results.py` 核验八个官方运行的配置、完整 epoch 和 step 数、零跳过更新、训练/测试身份互斥、训练配置所记录的每个代码文件 SHA256、SYSU 十个 gallery 的手动复算均值，以及评测时不使用 reranking/test flip。保存的 `results/official_pilot_v1_summary.json` 含每次运行的配置数量、最终 epoch 诊断、结果档案哈希及本地 checkpoint 哈希。原图、压缩包和 checkpoint 均留在本机并由 Git ignore 排除；推送的 JSON 不含图像或权重。

BCRT 的 SYSU 短预算 all-search 比 AGW 高 1.59 Rank-1、1.73 mAP points；但低于普通 center 对照 0.20 / 0.13 points。Indoor BCRT 的 Rank-1 也低于 AGW、center 和 unbounded。第 20 轮只有约 1.83% donor directions 的步长被截断，远不足以把观察到的差异归因于边界上限。故两个数据集的结果都支持“继续做机制/强度诊断”而不支持“已有有效创新”。
