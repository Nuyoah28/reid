# 论文框架与当前可支持的论点

工作题目：面向真实遮挡泛化的受控干预可靠性学习。

这是研究提纲，不是已可投稿的成稿。写作时应根据本轮实际结果决定保留、重构还是放弃候选假设，不能先写好“显著优于现有方法”再选择实验。

## 引言的逻辑

1. 遮挡同时造成信息缺失和外观干扰。人体解析、视觉语言模型和图库补全可提供额外线索；本文聚焦仅凭输入图像学习可见区域的可靠性，并验证合成遮挡监督能否迁移到真实遮挡。
2. 输入空间的几何可见性只是近似：遮挡物经过感受野和门控后可能改变矩形外的特征。该现象符合已有CNN机制，不把它包装成首次发现。
3. 研究问题：能否通过同一图像、同一位置下替换遮挡外观生成更合适的空间可靠性监督，并在测试时只预测该监督？
4. 配套问题：一致性监督应匹配共同剩余证据，还是要求遮挡图复现完整干净表征？当前只实现了前者，缺少后者的直接对照，故结论必须克制。

## 相关工作应分开的概念

- OSNet是直接复用的 baseline，引用 ICCV 2019 原论文；选择它是为了沿用现有实验基线，不把轻量化作为论文贡献。
- ADP/SPT/SSSC说明遮挡增强和干净–遮挡约束已经存在。
- RGANet/ProFD说明可靠性、可见性和部位匹配也已经存在。
- CAL说明反事实注意力与ReID不是本项目首次结合。
- COPE与本项目改变的变量不同：跨身份固定遮挡，对比同目标替换遮挡。必须比较监督目标，而不能仅比较命名。
- BPBreID、ProFD等现代方法未在本机复现；论文不能把其原文成绩放在自测表里并冒充相同条件。

## 方法章节

完整公式与训练流程见 `研究方案.md`。把候选贡献集中在两个具体设计上：

1. 同图受控遮挡外观替换产生的污染校准目标 `v exp(-d/tau)`。
2. 同一停止梯度证据支持下的教师重池化与相对证据预算加权。

小卷积头、标准weighted pooling、BCE、深度卷积、停止梯度、普通蒸馏均不单独声称原创。正文应解释伪标签并非人体真实可见性、稳定背景未必有身份判别性，以及合成干预到真实遮挡的域差异。

## 实验章节

先报告开发协议和失败配方，再报告冻结后测试，避免掩盖超参数筛选。模块表包含 aug、visibility、clcp、full；plain提供官方架构的基础能力，注明一视图与三视图计算差异。

机制诊断已发现矩形外漂移，但 full 没有降低漂移，不能据此写“学到更不变特征”。开发集主要指标也未超过 aug。冻结后，full 在 Market 的 50% 合成噪声 mAP 为 17.58，比 aug 的 16.04 高 1.54 点；但真实 Occluded-REID mAP 为 46.85，低于 aug 的 48.50，Rank-1 也由 54.80 降至 52.00。不加合成遮挡的 plain 在真实域达到55.73 mAP / 62.10 Rank-1，是四组中最好的；不能省略这一对照。当前主要真实遮挡指标不支持完整方法有效，也未支持所用增强迁移到该真实域。不能把合成压力测试的局部收益写成真实遮挡的普遍改善。完整变体结果与计算预算差异见 `实验记录.md`。

参数量与设备延迟可在实现说明中作为补充背景，不作为核心假设、主要比较维度或论文贡献。现有单次测量不支持稳定加速结论。

## 投稿前的决策

本轮按用户要求只做大致模块对照。候选在真实遮挡主要指标没有超过普通增强，应先检查稳定背景被赋高权重、伪标签漂移以及增强到真实域差异等解释，具体后续对照见 `下一步研究决策.md`。待机制和效果获得支持后，再补充种子、现代方法对照和独立数据集，评估投稿价值。候选 CCF C 会议的当年分类与截稿时间尚未独立核实。
