遮挡 ReID v3/v4：baseline 与结构对照

输入一张 RGB 行人图像，OSNet x1.0 输出空间特征；baseline 直接做全局平均池化。三个结构对照分别在同一个 16×8 特征图上加入单层空间 Transformer、语义筛选高频细节融合或 Restormer 启发的 MDTA 通道注意力，最后复用同一 FC 与 512 维检索接口。

图中结构都已按各自冻结协议进行比较，但实验结果不代表有效性已证实。卷积骨干均来自官方 deep-person-reid 固定版本；训练时另用身份分类器，检索时不调用分类器。

1. Baseline：逐阶段空间尺寸与采样位置

下采样发生在初始 MaxPool，以及 conv2/conv3 首个 OSBlock 后的 Conv1x1 + AvgPool2d(2)。conv4 不降采样；最终 16×8 空间网格供所有 v3 结构共享。

2. Baseline 细节：每个 OSBlock 与卷积单元

LightConv3×3

Conv1×1 M→M (bias=False) → depthwise Conv3×3 (groups=M, bias=False) → BatchNorm2d → ReLU。空间尺寸不变；1×1 混合通道，depthwise 3×3 提取局部空间信息。

多尺度路径

四路分别串联 1、2、3、4 个 LightConv，最大有效感受野逐路增加。四路中间宽度 M=Cout/4；OSBlock 的路径结构、通道门控和残差均来自 OSNet 原文／官方实现。

3. 三种 v3 结构在共享特征图后的细化

3.1 Baseline 路径：不加空间适配器

3.2 普通单层空间 Transformer（结构对照）

输出 token 恢复为 [B,512,16,8]，再走 baseline 的 GAP、FC、L2 normalization。Transformer 仅一层；输入位置编码是可学习的 128×512 参数，两个残差缩放均初始化为 0.1。

3.3 Semantic Detail Fusion（自设候选）

此候选把低频全局语义用作 query，对低频局部位置打分，再把所选位置的高频残差汇聚成上下文，并由空间 gate 控制向原特征回注的强度。该机制目前只是一项可证伪设计假设：遮挡物边缘和背景也会产生高频响应，实际收益只能由完整配对实验判断。

3.4 单层 MDTA 通道注意力（v4 候选／负向对照）

该结构采用逐空间位置的 channel LayerNorm、1×1 QKV、depthwise 3×3、空间维归一化后的通道相关性和 1×1 输出投影；残差尺度初值为 0.05。它只测试 MDTA，不包含 Restormer 的 GDFN，后接 baseline 的 GAP／FC。每头中 C/head=128 恰与 H×W=128 数值相同，但注意力矩阵两个轴代表通道，空间轴只用于计算相关性。

4. 来源、年份与创新边界

模块或设计来源与时间本实现中的处理
OSNet x1.0、OSBlock、LightConv、ChannelGateZhou et al., Omni-Scale Feature Learning for Person Re-Identification, ICCV 2019；固定版本官方 deep-person-reid，MIT License。骨干原样使用，是 baseline，不是本阶段创新。输入／输出、下采样和各卷积块配置均按官方代码展开。
Self-attention 与前馈 Transformer 层Vaswani et al., Attention Is All You Need, NeurIPS 2017。用 PyTorch MultiheadAttention 与标准两段残差构成单层结构对照。标准 Transformer 的使用不作为原创贡献。
全局语义排序高频局部细节的启发Li, Chen, Ye, Adaptive High-Frequency Transformer for Diverse Wildlife Re-Identification, ECCV 2024, DOI 10.1007/978-3-031-72784-9_17。仅借鉴全局语义帮助筛选局部高频位置的研究思路。没有复现论文的 ViT CLS-to-patch、FFT/FMA 或 Feature Equilibrium 损失。
Semantic Detail Fusion 的具体计算图本项目结构设计，2026；在 v3 中实现和比较。OSNet pooled low-frequency query、3×3 局部平均高通、top-50% cosine token 筛选和空间残差门控是对特征形态作出的自设组合，不因“自设”就自动构成论文新颖性；需要查重、消融和独立数据集验证。
MDTA 通道注意力Zamir et al., Restormer: Efficient Transformer for High-Resolution Image Restoration, CVPR 2022, DOI 10.1109/CVPR52688.2022.01167。只移植单个通道注意力残差算子到 OSNet 特征图；不含 Restormer GDFN。该移植是对照，不是原创贡献。与 TIP 2024 二阶注意力工作的精确重合尚未能核实。
Mamba 与遮挡 ReID 的先例ReIDMamba, IEEE TMM 2026；另有 TE-VMamba, CVPR 2026。它们说明 Mamba 已进入 ReID 研究。本 v3 未实现或声称借用 Mamba 模块，也不把 Mamba 作为本实验贡献。
实验边界：v3 的 Occluded-REID 在 v1/v2 中已经查看过，所以这里的指标属于探索性迁移，不是盲测结果。短训练和两个 seed 只能用于可行性筛选，不能支持显著性或 SOTA 结论。

Adaptive High-Frequency Transformer：DOI 10.1007/978-3-031-72784-9_17。
