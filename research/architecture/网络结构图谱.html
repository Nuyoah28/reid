② 当前 full 候选模型：OSNet + 可靠性加权池化

与 baseline 的实际差异：保留同一 OSNet 主干及 FC；将均匀 GAP 换成可靠性加权平均，可靠性图来自新增小头。训练中 full 额外使用配对遮挡视图、可靠性校准和剩余证据一致性；推理中不计算这些监督项。

结构追踪统计：751 类时，完整训练模型 2,571,572 参数，其中训练分类器 385,263；推理路径 2,186,309，可靠性头 16,801。统计为参数量而非 FLOPs；类别数改变会改变分类器参数。

③ OSBlock：六个多尺度块的内部结构

来源：OSNet 官方实现，Zhou 等，ICCV 2019。三个阶段各两个 OSBlock，共六个；每个块内部保留四个尺度分支和残差连接。所有块形状由下表参数决定。

LightConv3x3：一个轻量卷积单元

1×1 Conv M→M, bias=False → depthwise 3×3, groups=M, stride=1, padding=1, bias=False → BN2d → ReLU。

1×1 先混合通道，深度卷积逐通道提取空间信息。分支连续堆叠 1、2、3、4 个这样的单元，获得不同感受野。四个分支合计 10 个 LightConv；六个块共 60 个。

轻量卷积是已有构件；图中具体顺序与实现来自 OSNet，而不是本项目新设计。

门控与残差

每一分支独立计算其 GAP，然后使用同一个 ChannelGate 的权重生成通道系数；四次调用共享参数，但输入和输出门值各自不同。汇总后 1×1 Conv+BN 扩展通道，与 shortcut 相加再 ReLU。

门控中的 1×1 Conv 有 bias；M/16 为整数。普通骨干和 shortcut 卷积无 bias，且 OSBlock 标准 x1.0 不使用 IN。

④ 可靠性头与加权池化逐层拆解

来源：本项目用标准卷积、GroupNorm、SiLU、sigmoid 和加权平均组合实现；不能把单个已有算子或该简单组合直接声称为原创模块。它是候选可靠性目标的预测载体。

权重的下限 0.05 防止特征被完全清零；同一空间权重广播到 512 个通道。F.detach() 意味着分类与校准损失无法通过头部改变主干，但分类与三元组损失仍能经加权特征的主路径更新主干；预测头本身也可从加权池化的识别损失和校准损失学习。该图是遮挡外观变化下的稳定性预测，并非人体分割图。

⑤ full 训练流程与梯度方向

目标与损失的精确定义

v = AdaptiveAvgPool(矩形外为 1、矩形内为 0 的可见掩码, 16×8) dᵢ = max(0, 1 − cosine(Fᴬᵢ, Fᴮᵢ)) tᵢ = stopgrad[vᵢ · exp(−dᵢ / τ)]，默认 τ=0.15 wᵢ = 0.05 + 0.95 · sigmoid(rᵢ) L_cal = ½[BCEWithLogits(rᴬ, t) + BCEWithLogits(rᴮ, t)] Pₜ(F) = Σᵢ tᵢFᵢ / max(Σᵢtᵢ, 10⁻⁶) c = ½[(1−cos(Pₜ(Fᴬ), Pₜ(stopgrad(Fclean)))) + (1−cos(Pₜ(Fᴮ), Pₜ(stopgrad(Fclean))))] L_evidence = Σ_batch[c · mean(t)] / max(Σ_batch mean(t), 10⁻⁶) L_total = L_CE + 0.5 L_triplet + 0.5 L_cal + 0.5 L_evidence

CE 使用标签平滑 0.1；三元组损失使用 L2 归一化特征、批内最难正负样本、margin 0.3。系数和温度为默认参数，可通过命令行更改。校准只监督 A、B，没有强制原图每个位置都等于 1；目标计算本身在无梯度上下文中完成。剩余证据一致性作用于主干特征，不经过 FC 或可靠性预测权重。
