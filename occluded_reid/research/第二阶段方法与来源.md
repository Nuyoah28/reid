# 第二阶段：由跨图身份证据校准遮挡可靠性

本阶段研究方向是 **RGB 遮挡行人重识别中的身份证据保留与真实遮挡泛化**。不把轻量化、压缩或小参数量作为贡献。OSNet 是可在现有 RTX 4060 上执行受控实验的基线，不能因此将研究方向重新定义成轻量化 ReID。

本文件说明设计；实验结论以 [第二阶段实验报告](第二阶段实验报告.md) 为准。第一阶段的负结果完整保留在 [历史实验记录](实验记录.md)。本阶段的协议在训练开始前保存为 [occlusion_v2_protocol.json](occlusion_v2_protocol.json)，不根据本轮结果改写。

## 1. 新模块针对什么问题

旧 CLCP 用两次遮挡物替换后的特征相似度生成可靠性目标。两个视图都稳定的区域可能是背景、重复纹理或弱身份线索，**稳定性本身不等于身份判别性**。旧实验在合成噪声上有局部收益，在真实 Occluded-REID 上无优势；因此新阶段检查目标定义，而不是直接加大网络或延长训练。

本阶段的候选称为“跨图身份证据校准”（代码前缀 `peer`；仅为项目内部名称）。保持增强、可靠性头和检索路径不变，把可靠性监督改成：一个位置必须在两种遮挡物下，都更像同身份的其他原始图片，而不是当前批次其他身份。它是 **训练监督机制候选**，不是新骨干，也不是已证实的新颖方法。

宽泛的“判别性 + 不变性置信度”已出现在 RGANet（TIFS 2024）。原型、注意力池化、sigmoid、最小值和一致性均有既有研究基础，不能单独当作原创。

## 2. 输入、采样与共享骨干

输入为 `B=24, C=3, H=256, W=128`，按 6 个身份 × 每个身份 4 张源图采样。同一个源图经 resize、随机翻转、padding 10、随机裁剪、ImageNet normalize 后得到 `x`。

`paired_occlusion` 对每张 `x` 固定同一矩形位置，从当前训练批次其他身份挑选两个 donor，生成 `xa`、`xb`。第二个 donor crop 会水平翻转；面积参数采自 `[0.15,0.45]`，经宽高约束裁剪后，实际面积可能不同。两个 donor 是训练图像片段，**不等于经过分割的纯遮挡物**。二值图 `V=1` 表示未被矩形覆盖，不能将它当作人体前景真值。

三视图拼接为 `72×3×256×128`，一次经过共享 OSNet x1.0，得到 `F0, Fa, Fb`，每项 `24×512×16×8`。同一次 forward 中 BatchNorm 也受三视图分布影响；所有新阶段对照都使用三视图预算。

651 个训练身份中 12 个身份不足 4 张，最少为 2 张。`PeerPKSampler` 对此先遍历可用源图，再有放回补足；不丢掉这些身份。target 排除 anchor 的所有重复源图，并按源图出现次数倒数加权，避免重复 draw 获得更多票数。重复源图的不同随机增强仍可能给出不同特征，其总权重是一张图。不能把它表述为“每身份都有 4 张不同源图”。

## 3. 身份证据目标的精确定义

记 `g_j = GAP(F0_j)`，`y_j` 为训练身份，`u_j` 为源图索引，`w_j = 1 / count(u_j)`。下述分支全部在 `torch.no_grad()` 内，clean 与两遮挡视图的特征都停止梯度。

**同身份其他源图正原型**：

```text
P_i = {j : y_j = y_i 且 u_j ≠ u_i}
p_i = L2Norm( Σ[j∈P_i] w_j g_j / Σ[j∈P_i] w_j )
```

排除自身及其重复源图，避免用自己的全局描述对自己的局部证据作循环确认。但其他源图仍可能共享背景，这并不保证前景隔离。

**批内其他身份负原型**：

```text
n_c = L2Norm( Σ[y_j=c] w_j g_j / Σ[y_j=c] w_j )
m_v(i,s) = cos(Fv_i(s), p_i) − max[c≠y_i] cos(Fv_i(s), n_c)
v ∈ {a,b}；s 是 16×8 空间网格上的位置
```

每个位置比较“同身份支持”与批内最相似的其他身份。负原型只覆盖当前批次 5 个其他身份，不能等同于全训练集 hard negative；没有持久 memory bank。局部特征与全局原型比较存在尺度和语义错配风险。

**要求两个干预视图都保留身份支持**：

```text
G = AdaptiveAvgPool2d(V, 16×8)
I_i(s) = sigmoid( min(m_a(i,s), m_b(i,s)) / 0.1 )
T_peer = G · I
```

`min` 是保守的交集式准则：一个 donor 下身份支持变差，目标就会降低；不把一个视图的高支持平均掉另一个视图的失败。这个选择也可能过于保守，特别是短预算时骨干尚未形成可靠原型。`T_peer` 是生成的软目标，不是可见性标注或正确身份概率。

**联合旧外观稳定性**：

```text
D = max(0, 1 − cos(Fa(s), Fb(s)))
A = exp(−D / 0.15)
T_joint = G · I · A
```

`peer_stability` / `peer_evidence` 使用 `T_joint`；`peer` 使用 `T_peer`；`stability` 使用旧 `G·A`。几何项只乘一次。超参在本阶段不调优。

## 4. 可靠性头、池化与梯度

| 路径 | 实际算子 | 输出 | 来源与作用 |
|---|---|---|---|
| OSNet | stem；6 个 OSBlock；两次 stage 平均池化；conv5 | `B×512×16×8` | Zhou et al., ICCV 2019，官方固定源码 |
| 头部输入 | `F.detach()` | 同上 | 沿用 v1；截断可靠性卷积分支对骨干的直接梯度 |
| 通道压缩 | Conv1×1 512→32，bias=False；GroupNorm(4,32)；SiLU | `B×32×16×8` | v1 项目组合，通用算子，无新贡献声明 |
| 空间处理 | depthwise Conv3×3 32→32，groups32，padding1；SiLU | `B×32×16×8` | v1 项目组合，不宣称新注意力架构 |
| 可靠性 logits | Conv1×1 32→1 | `B×1×16×8` | 同上；末层 weight=0、bias=2 初始化 |
| 池化权重 | `W = 0.05 + 0.95·sigmoid(logits)` | 同上 | v1 下限保护，避免所有位置同时被丢弃 |
| 特征汇聚 | `z = Σ(W·F) / max(ΣW,1e−6)` | `B×512` | 标准加权平均 |
| 检索头 | Linear512→512；BN1d；ReLU；评测 L2 normalize | `B×512` | 官方 OSNet FC + 本项目检索归一化 |
| 训练分类器 | Linear512→651 | `B×651` | 常规身份分类；本轮 651 类，旧正式实验 751 类 |

校准损失对两个遮挡视图各做 `BCEWithLogits(reliability_logits, T)` 后取平均。没有 clean 图的显式校准 BCE，但 clean 图也使用预测权重计算检索损失。头部会同时接收到校准损失与检索损失的梯度，因此不能将输出称为“纯粹拟合可靠性”的独立估计器。`detach` 只切断头部输入回到骨干的支路，池化中的 `F` 仍有检索梯度。

## 5. 沿用的一致性损失

`peer_evidence` **直接复用 v1 `surviving_evidence_loss`**，只把传入目标替换为 `T_joint`：用相同 `T` 对 clean、a、b 重池化；clean 教师停止梯度，两个遮挡分支以 cosine 距离靠近它；各样本按目标均值加权。它不是本阶段新提出的第二个模块，也不是复制 ProFD 的 memory distillation。

目标趋近零时，损失可能提供很少信号；局部判别证据和一致性不一定兼容。必须通过 `peer_evidence − peer_stability` 判定增减效果，不能因为概念合理就保留。

总损失为：

```text
L = CE(label smoothing 0.1)
  + 0.5 · mean(每个视图各自的 batch-hard triplet)
  + 0.5 · calibration_BCE（有头变体）
  + 0.5 · surviving_evidence（仅 peer_evidence）
```

不跨三个视图挖 triplet，以免把相同源图复制误当成额外独立正样本。

## 6. 对照与解释边界

| 变体 | 输入 | 池化 | 校准目标 | 额外一致性 |
|---|---|---|---|---|
| repeat3 | 同一个已增强 tensor 复制 3 份 | GAP | 无 | 无 |
| paste3 | clean + a + b | GAP | 无 | 无 |
| stability | clean + a + b | 可靠性加权 | `G·A` | 无 |
| peer | clean + a + b | 相同可靠性头 | `G·I` | 无 |
| peer_stability | clean + a + b | 相同可靠性头 | `G·I·A` | 无 |
| peer_evidence | clean + a + b | 相同可靠性头 | `G·I·A` | 旧 v1 损失 |

`repeat3` 也执行 donor 生成来消耗相同随机数序列，但将三份 clean tensor 输入网络；它**不是三次独立随机常规增强**。因此只消除了批图数等预算差异，未覆盖独立视图多样性这个问题。

`stability − paste3` 是头部、加权池化和监督一起的组合差异；不能单独归因于稳定性目标。`peer − stability` 保持相同头结构，直接检验目标替换。后两个配对分别检验稳定性衰减与旧一致性损失。两种子仅为可行性筛查，不能证明统计显著性或充分收敛。

## 7. 逐项来源与原创性清单

| 部分 | 归类 | 可追溯来源 | 本项目实际做了什么 |
|---|---|---|---|
| OSNet x1.0 / OSBlock / ChannelGate / FC | 原样引用 | Zhou et al., ICCV 2019；`deep-person-reid` commit `f8cd150f...`，MIT | 固定并继承官方骨干，没有把它包装成自己的网络 |
| 遮挡矩形粘贴 | 已有范式 + v1 具体实现 | 遮挡增强已有大量先例；SPT, AAAI 2024 使用 saliency/OIoU/mask rolling | 本项目保持矩形固定、换两个其他身份 donor；没有实现 SPT 的显著性等模块，不能称“引入 SPT 模块” |
| 外观稳定性目标 | v1 自定候选，v2 原样沿用 | `reid/occlusion.py::influence_target`；反事实注意力思想可联系 CAL, ICCV 2021 | 直接在特征图测 donor 变化，不复现 CAL 分类因果效应损失 |
| 可靠性头与带下限池化 | v1 通用算子组合 | Conv / GroupNorm / SiLU / weighted pooling | v2 未改网络层；不作为新的主要贡献 |
| 跨源图正原型与批内负原型 margin | 本阶段自行实现的监督候选 | 原型学习是既有范式；DPM 2022 等是必须比较的相关工作 | 排除 anchor 源图；重复源图一票；局部 identity margin；target 全停止梯度 |
| 两干预 minimum 生成空间 target | 本阶段设计选择 | minimum/sigmoid 本身通用；v1 成对 donor 机制 | 要求不同 donor 下都有身份支持，用于校准单图可靠性头；本轮实测未支持真实遮挡优势，不声称首次 |
| `G·I·A` | 本阶段联合目标候选 | RGANet 已有判别性/不变性联合评估概念 | 不引用其 CLIP/部位 memory bank；本项目是训练期视觉身份 margin 的空间监督 |
| surviving-evidence loss | v1 原样复用 | 本仓库旧实现 | 只改变传入 target，不能列为本阶段原创新模块 |
| PK 采样、CE、Triplet、AMP、Adam | 常规工程与损失 | 标准训练工具 | 保证稀疏身份的跨图正支持和可审计预算；不列为论文创新 |

这不是“多个现成论文模块拼接后全部宣称原创”。本阶段真实新增的是一套可证伪的监督构造；其学术新颖性仍需要结合全文查重和更强对照。即使实测为负，也保留实现、协议和结果，不改名掩盖失败。

## 8. 与重点论文的区别及未排除风险

**RGANet, TIFS 2024**（DOI `10.1109/TIFS.2023.3318956`；DOI 含 2023，不代表正式卷年）：已读本地 R0624 方法部分和 Eq.4–10。它使用 CLIP 语义部位原型生成区域，RAM 结合 learned FC 的 discrimination indicator 与人体部位类别 memory bank 的 invariance indicator；不是训练身份 memory bank。项目不用这些模块，改为同身份其他源图的视觉 margin 生成停止梯度的空间校准目标。“判别性与不变性联合”本身不新。

**ProFD, ACM MM 2024**（DOI `10.1145/3664647.3680958`，Crossref 日期 2024-10-28）：使用文本部位提示、外部 noisy segmentation、hybrid attention 和 memory self-distillation。本项目没有移植其模块，也没有 CLIP/分割标签；因此不能把本项目一致性包装成“引用 ProFD 并改进”。

**DPM, ACM MM 2022**：Dynamic Prototype Mask for Occluded Person Re-Identification，DOI `10.1145/3503161.3547764`。其原型掩码与本项目主题直接相关；全文核查结论另见 [原型方法查重记录](原型方法查重记录.md)。

**TGPG, IEEE SPL 2024**：Text-Guided Prototype Generation for Occluded Person Re-Identification，DOI `10.1109/LSP.2024.3456007`。目前只获得元数据和索引摘要；描述文本引导 mask prototype 生成与 intra-modality spatial consistency。未读全文，不据此宣称排除方法重合。

在线元数据查询、URL、返回码、哈希和本地 PDF/全文哈希见 [第一份来源审计](occlusion_v2_source_audit.json) 与 [原型专项审计](prototype_prior_art_audit.json)。这不是穷尽查新，也不是截至 2026 年最新 SOTA 排名。

## 9. 实现入口

- `code/occlusion_v2/method.py`：原型、margin、目标与损失切换。
- `code/occlusion_v2/data.py`：源图索引与稀疏身份采样。
- `code/train_occlusion_v2.py`：冻结配方、停止梯度/训练路径、AMP 实际跳步、source/checkpoint/data manifest 哈希。

- `tools/run_occlusion_v2.py`：6×2 顺序训练，全部训练完成后再冻结并外测全部模型。
- `code/tests/test_occlusion_v2.py`：身份语义、排除自身、重复去权、最小值、停止梯度、采样和反向验证。
- [第二阶段网络图](architecture/第二阶段网络图.html)：训练目标、推理路径、baseline 和各卷积/采样块。
