## 数学定义

当前一个 batch 含 P 个身份，并保证每个身份各有 VIS、IR 样本。先令每张图的 GeM 向量归一化为 `z_i`。身份 j 的两个模态均值为 `cᵛ_j` 和 `cᵗ_j`，构造中心与模态残差：

```text
p_j = stopgrad((cᵛ_j + cᵗ_j) / 2)
δ_j = stopgrad(cᵗ_j - cᵛ_j)
```

对身份 y 的锚点 z，只借用其他身份 j≠y 的模态残差。可见光锚点的方向 `d=+δ_j`，红外锚点方向 `d=−δ_j`。这里不把供体身份标签赋给锚点，也不把锚点身份自己的残差重复灌回自身。

对每个异身份原型 k≠y 定义未归一化欧式距离差：

```text
g_k(t) = ||z + t d - p_k||² - ||z + t d - p_y||²
       = g_k(0) + t · a_k
a_k   = 2 d · (p_y - p_k)
```

给定候选最大步长 α 和保留比例 ρ∈[0,1]，只要求当前 batch 固定原型的线性欧式间隔至少保留 `ρ g_k(0)`。若方向向着负间隔（a_k<0），对应步长上界为：

```text
u_k = (1 - ρ) g_k(0) / (-a_k)
t   = min(α, min_{k≠y, a_k<0} u_k)
```

代码参数为 α=0.5、ρ=0.5。若任一初始 `g_k(0)≤1e−6`，该 anchor 标为不合格，在 BCRT 与无约束对照里共同排除。其他候选步长方向安全时，不额外压低步长。固定原型、供体方向和 `t` 均停止梯度；虚拟点 `v=L2(z+td)` 仍向当前锚点和共享编码网络传播原型 CE 梯度。总目标为：

```text
L = L_ID_CE + L_WRT + λ L_virtual_CE
λ = 0 for first 5 epochs, then 0.2
```

prototype logits 使用归一化原型的余弦值除以温度 0.1；该 CE 是训练期优化信号。推理不需要 prototype、donor 或额外 classifier，仍输出归一化 BNNeck 2048 维向量。

## 保证范围与风险

闭式步长只保证**该 batch 的固定、未归一化欧式中心**之间，虚拟点在直线移动时保留指定比例的初始距离差。它不保证后续 L2 归一化余弦分类边界、真实图像流形、测试身份、跨 seed 或数据域上的性能。prototype 由有限 batch 均值估算；抽样噪声可能令边界证书不稳定。

若候选步长极少被截断，BCRT 与 unbounded 的实际训练接近，约束主张就缺少作用证据；若合格率低，辅助监督样本会稀少；若检索结果不升，必须报告无效。不能单凭零几何违规宣称识别准确率提升、鲁棒性或投稿级原创性。

相邻工作已涉及多特征生成和可学习原型，例如 Prototype-Driven Multi-Feature Generation (ICASSP 2025, arXiv:2409.05642)；模态知识分解例如 IDKL (CVPR 2024)；频域调制例如 MFEN (CVPR 2026)、FDNM (TIFS 2025)；遮挡下频空协作例如 SFCL (CVPR 2026)。目录还列有 “Transporting the Cross-Modal Prototypes for Unsupervised Visible-Infrared Person Re-Identification” (TIP 2026, DOI `10.1109/TIP.2026.3680065`) 与 “Negative Semantic Guided Identity Boundary Construction for Open-World Person Re-Identification” (TMM 2026, DOI `10.1109/TMM.2026.3651057`)。这两篇尚未取得全文；题目层面已经显示 prototype transport 和 identity boundary 是高风险重叠词。取得全文并实质性对照前，不应声称 BCRT 具有学术首创性。本项目未复制已阅论文的完整模型或代码。还需补查检索/域泛化、边界约束增强、mixup/对抗扰动等领域，才可在论文中评估优先权。
