# 轻量化遮挡 ReID：历史方向归档

用户已于 2026-11-14 确定只做遮挡 ReID，并确认此目录仅用于保留历史方向，不继续作为论文主线。

此前对轻量化的讨论没有形成独立于 OSNet 遮挡原型的、具有独立训练结果的模型。为避免把相同结果复制成两项成果，此目录不虚构第二份实现、实验或轻量化贡献。

历史 OSNet 代码、参数量背景与原始实验保存在 [遮挡项目](../occluded_reid/README.md)，详细来源见 [baseline 清单](../occluded_reid/research/baseline_source.json)。OSNet 的卷积设计来自 ICCV 2019 原论文；其已有轻量特性不属于本项目创新。

当前任何新增模块、实验与论文撰写均在 `../occluded_reid/` 进行。
