# 第二阶段原型机制专项查重

检查时间：2026-11-14。范围为与当前目标直接相关的 RGANet、DPM、ProFD、SPT，以及 TGPG 的元数据/摘要；不是穷尽综述，也没有据此确认“首次提出”。

## DPM：不能再声称“首个原型辅助遮挡方法”

Tan, Dai, Ji, Wu. **Dynamic Prototype Mask for Occluded Person Re-Identification**. ACM MM 2022, pp. 531–540. [DOI](https://doi.org/10.1145/3503161.3547764)，[arXiv 原文](https://arxiv.org/abs/2207.09046)，[作者代码](https://github.com/stone96123/DPM)。

已取得作者 arXiv v1 PDF（2022-07-19，10 页），保存在共享 `reference-paper/DPM_2022_arxiv_2207.09046.pdf`，不上传 Git。重点阅读 PDF 第 2–5 页的动机、Fig.2、§3.1–3.4 / Eq.3–8；第 3、4 页已渲染并视觉核对。元数据、下载返回码、PDF 与抽取全文 SHA256 见 [专项审计 JSON](prototype_prior_art_audit.json)。论文实验章节作为协议背景阅读，不用其数值给本项目短训练结果排名。

| 比较项 | DPM 2022 原文 | 本项目 peer / peer_stability |
|---|---|---|
| 表征骨干 | 预训练 ViT，含位置、相机 embedding | 官方 OSNet x1.0，当前仅图像输入 |
| 原型是什么 | 身份分类器权重矩阵视作 holistic identity prototypes | 同批 clean 特征平均得到临时视觉原型；非分类器权重 |
| 正原型来源 | 可学习的全训练身份分类权重 | 同身份其他源图；排除 anchor 源图及重复副本 |
| mask 的维度与对象 | HMG 产生通道/特征模式 mask，乘到 prototype 权重上，选择匹配子空间 | 身份 margin 产生 16×8 空间软目标，监督可靠性头；不裁剪分类器原型 |
| mask 如何产生 | 2/4/10/12 层 token maps 拼接，卷积、GAP、sigmoid | 两遮挡视图局部特征到正/负原型的 cosine margin，取 min，再 sigmoid；全停止梯度 |
| 判别性约束 | masked classifier angular-margin loss | 用批内 hardest negative 的 margin 作为 target 来源；另保留普通 CE / Triplet |
| 多样性 | HEM 对最后层多头 attention 的相关矩阵作正交约束 | 无 ViT 多头、HEM 或对应正交损失 |
| 推理匹配 | §4.1 将 query 生成的 mask 应用于 gallery 后进行匹配 | 每张图独立生成归一化 512 维向量；检索时没有身份原型或 query 条件的 gallery mask |
| 对遮挡物的控制 | §3 的方法构造不依赖本项目这类固定几何双 donor 目标 | 同一源图、同一矩形、两个其他身份 donor；最差视图决定身份支持 |
| 是否移植其代码 | — | 未复制、未改写 DPM HMG/HEM；仅阅读对照 |

因此，本项目不是 DPM 的逐层复现或简单改名。但 DPM 已将“高质量身份原型 + 选择可见判别子空间”作为核心动机，足以限制我们的宽泛新颖性表述。更恰当的候选差异是 **其他源图身份支持在两个受控干预下的空间校准监督**，而不是“提出原型解决遮挡”。不同实现也不自动等于足够论文贡献。

## RGANet：判别性与不变性联合评估已有先例

He et al. **Region Generation and Assessment Network for Occluded Person Re-Identification**. IEEE TIFS 2024. [DOI](https://doi.org/10.1109/TIFS.2023.3318956)。本地论文 R0624；Crossref 核对正式出版年为 2024。

RGANet 用 CLIP 文本/人体部位语义生成区域。RAM 的 discrimination-aware indicator 为学习的 FC/sigmoid；invariance-aware indicator 使用 **部位类别** memory bank 与相似度，两个分数联合为区域重要性。本项目身份原型并非其部位 memory 的复现，且我们生成的是不反传的监督目标。但“稳定 + 有区分力”不属于可主张的原创概念，必须引用并讨论。

## ProFD、SPT 与 TGPG 的获取范围

- **ProFD, ACM MM 2024**：已读本地 R0369 方法。文本提示、noisy segmentation 对齐和 memory self-distillation 未被本项目移植；不能把旧一致性 loss 说成其新变体。
- **SPT, AAAI 2024**：已读本地 R0354 方法。saliency、OIoU、mask rolling 是其具体设计，本项目只是简单矩形 donor 粘贴；遮挡增强不是新的范式。
- **TGPG, IEEE Signal Processing Letters 2024**：[DOI](https://doi.org/10.1109/LSP.2024.3456007)。只得到 OpenAlex 索引摘要，尚未取得全文。摘要明确提到 text-guided mask prototype generation 与 intra-modality spatial consistency；不能排除更细粒度的相似设计，不杜撰其算子或公式。

## 对论文表述的约束

1. 目前只能说“实现并检验了一个候选监督构造”，不能说已证明新颖性、解决真实遮挡或达到最新 SOTA。
2. 必须将每个复用构件和本次新增构造分开，不能将旧一致性或通用原型学习重复列为独立新贡献。
3. 将来若投稿，需要扩展原型/置信度/干预监督的系统检索，并与更现代遮挡方法作公平训练对比；本次未将这些未来工作写成已完成实验。
4. 本次方法参数已在训练前固定。查重结果用于收紧来源表述，不在看到实测数字后更换公式。
